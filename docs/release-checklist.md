# План первого публичного релиза

Документы подготовлены, но публикация не выполнена. Утверждённое публичное название:
**Tabest — Fuzzy Tab Finder**. Короткое имя — **Tabest**.

По запросу владельца сейчас выполнены выбор имени, лицензии и переименование.
Автор, GitHub, графика, CI, дополнительные релизные проверки и отправка в магазин
отложены. Незаполненные пункты ниже не являются разрешением выполнять их сейчас.
Обязательные требования Mozilla остаются применимыми при фактической отправке.

  не обнаружила точного совпадения среди браузерных расширений; она не гарантирует
  юридическую свободу имени и не резервирует slug магазина.
- [x] Выбрать MIT и добавить `LICENSE`. Copyright notice: Tabest contributors;
  личное имя автора не указывается.
- [ ] При публикации проверить доступный AMO slug; сейчас отправка отложена.
- [ ] Определить автора, GitHub-аккаунт, репозиторий и контакт — отложено владельцем.
- [x] Сохранить add-on ID `telescope-browser@local.invalid`, чтобы переименование
  не сбросило данные установленного расширения. Это технический идентификатор,
  не публичное название и не настоящий email; совпадение ID проверит AMO при отправке.
- [x] Согласовать текущую разработческую версию 0.2.4. Первый публичный выпуск

## 3. Проверки релиза

- [ ] Зафиксировать среду Node/npm и версию `web-ext`; убрать плавающий инструмент
  из релизного процесса и проверить lockfile чистой установкой зависимостей.
- [ ] Собрать из отдельной чистой копии исходников без текущего `node_modules/`.
  Подтвердить воспроизводимость файлов расширения и поддерживаемые архитектуры.
- [ ] Запустить `npm test`, `npm run build`, `npm run lint:extension` после сборки.
- [ ] Запустить три изолированных Zen-сценария из [BUILDING.md](../BUILDING.md).
- [ ] Проверить стандартный Firefox desktop, не только Zen: загрузку, хоткей,
  preview, закрытие/выбор вкладок, фильтры, настройки и приватные окна.
- [ ] Проверить минимально заявленную версию Firefox либо обоснованно скорректировать
  `strict_min_version`; проверить ОС, которые будут заявлены поддерживаемыми.
- [ ] Проверить отзыв разрешения доступа к сайтам, защищённые/выгруженные страницы,

- [ ] Повторно сверить реальное поведение с `PRIVACY.md` и manifest. Сейчас указано
