# Интерфейс и клавиатурное управление

## Основное поведение

- Picker открывается отдельной служебной вкладкой, доступной из любой вкладки.
  Не превращай его в popup или внедряемый в страницы overlay без согласования.
- Интерфейс должен полностью управляться клавиатурой. В Insert обычные символы
  вводятся в поиск; в Normal работают команды, заданные в `src/keys.ts`.
- Сохраняй `j/k` для навигации, Tab/Shift+Tab для отметок, `dd` для закрытия,
  `p` для закрепления и `w` для области окон, если пользователь не переназначил их.
- Escape из Insert включает Normal; следующий Escape закрывает picker.
  Глобальный хоткей задаётся браузером, а не локальными привязками picker.

## Закреплённые вкладки и фильтры

`All windows / This window` и `All tabs / Pinned` — независимые фильтры.
По умолчанию в Normal `h` явно выбирает все вкладки, `l` — закреплённые.
Повторное нажатие не меняет выбранный режим. В Insert эти буквы остаются текстом.

Фильтр вкладок сохраняется между открытиями. При его смене сохраняй запрос
и выбранную вкладку, если она остаётся в результатах; иначе выбирай первую.
Снимай отметки с вкладок, скрытых сменой фильтра или области окон, чтобы `dd`
не удалил невидимую выборку. Пустой результат не должен мешать смене фильтра.

Закрепление не даёт бонуса к поиску и не меняет исходную сортировку:
с запросом важнее совпадение, затем недавность; без запроса — недавность,
а вкладка-источник остаётся в конце. Не добавляй приоритет pinned без согласования.

## Настройки и доступность

- По умолчанию используется компактный вид: без intro и footer, с более плотными
  строками. Кнопки Compact и Preview сохраняют вид и видимость preview в settings;
  старые настройки получают новые поля без перезаписи пользовательской раскладки.
- Подсказки под результатами отражают активный режим, отметки и закрепление
  выбранной вкладки; клавиши берутся из действующей раскладки. В Insert не показывай
  неработающие Normal-команды: подсказывай переход в Normal.
- Иконки вкладок берутся из favIconUrl браузера без внешнего сервиса поиска иконок.
  Если иконка отсутствует или не загрузилась, оставляй букву домена; не отправляй referrer.

- Новые привязки мигрируй без перезаписи пользовательских клавиш и последовательностей.
  Учитывай `keymapVersion` и намеренно удалённые привязки.
- Подсказки фильтров показывай в Normal и бери из действующей раскладки.
- Сохраняй фокус поиска после кликов по фильтрам. Отдельно показывай активную
  строку и отмеченные вкладки; поддерживай `aria-pressed` и состояние списка.
- Видимые тексты интерфейса сейчас английские. Не смешивай языки случайно.

## Геометрия и preview

Прокручивается список результатов, но не preview. Информация и действия preview
должны помещаться как со снимком, так и с заглушкой. Длинные тексты сокращай
с доступным полным значением, не допускай наезда статуса и нижней панели на строки.
На узких экранах фильтры должны переноситься без горизонтального переполнения.
Учитывай отсутствие разрешения, защищённые и выгруженные страницы, удаление вкладки
и устаревший ответ preview. Не расширяй разрешения ради обхода этих состояний.
