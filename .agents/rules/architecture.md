# Архитектура и стиль кода

## Структура проекта

- `src/background.ts` — вход фоновой части, проверка отправителей сообщений,
  последовательная очередь операций с вкладками и обработчики событий браузера.
- `src/controller.ts` — создание и закрытие picker, переключение вкладок,
  снимки состояния, недавность использования и защита закрытых ID.
- `src/picker.ts`, `src/style.css`, `picker.html` — интерфейс без UI-фреймворка.
- `src/search.ts`, `src/filters.ts`, `src/keys.ts` — поиск, фильтры, привязки
  клавиш и чтение настроек; `src/model.ts` — общие типы и сообщения.
- `src/previews.ts` — очередь и ограниченный кэш снимков;
  `src/preview-view.ts` — отложенный запрос и отображение preview.
- `src/browser.d.ts` — используемая поверхность WebExtensions API;
  `src/demo.ts` — демонстрационные данные без браузерного API.
- `public/` — manifest и иконка. `tests/` — модульные тесты;
  `scripts/` — изолированные проверки Zen и диагностика.
- `dist/` — результат Vite; меняй исходники, а не сгенерированные файлы.
- `README.md`, `PRIVACY.md`, `BUILDING.md`, `CONTRIBUTING.md` и `CHANGELOG.md` —
  публичная документация. `docs/` содержит тексты GitHub/AMO, заметки для ревью
  и чеклист публикации. Черновики не означают выполненную публикацию.

## Инварианты фоновой части

- Сохраняй сериализацию жизненного цикла вкладок. Захват preview выполняется
  отдельно и не должен блокировать очередь действий или хоткеи.
- Сигнал завершения `onRemoved` передавай вне очереди: операция закрытия может
  ждать его, уже удерживая очередь.
- Не активируй закрытые ID и не создавай обычную вкладку заново по сохранённому URL.
- Сохраняй существующий add-on ID и legacy-ключи предпочтений при косметическом
  переименовании: смена идентичности расширения может потерять текущие настройки.
- Не смешивай приватные и обычные окна ни в результатах, ни в кэше preview.
- Preview не должен активировать вкладку или будить выгруженную страницу.
  Учитывай отзыв разрешений, навигацию и поздние ответы захвата.

## Стиль и сборка

Используй строгий TypeScript, ES-модули, отступы в два пробела, одинарные кавычки
и точки с запятой. Функции и переменные — `camelCase`, типы и классы — `PascalCase`.
Следуй именованию соседних файлов, например `preview-view.ts`.
Локальные TS-импорты содержат `.ts`; импорты типов оформляй через `import type`.

Форматтер и отдельный линтер TypeScript не настроены. `npm run build` сначала
запускает `tsc --noEmit`, затем Vite с целью Firefox 140. Не добавляй новый
инструментарий форматирования ради несвязанной правки.
При выпуске согласуй версии в `package.json`, `package-lock.json` и
`public/manifest.json`; правки только документации не требуют новой версии.
