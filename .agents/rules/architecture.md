# Архитектура и стиль кода

## Структура проекта

- `src/background.ts` — вход фоновой части, проверка отправителей сообщений,
  последовательная очередь операций с вкладками и обработчики событий браузера.
- `src/controller.ts` — создание и закрытие picker, переключение вкладок,
  снимки состояния, недавность использования и защита закрытых ID.
- `src/work-sessions.ts` — независимые рабочие сессии Tabest: каталог, принадлежность
  вкладок, текущая сессия каждого окна и автоматическое добавление новых вкладок.
- `src/picker.ts`, `src/style.css`, `picker.html` — интерфейс без UI-фреймворка.
- `src/search.ts`, `src/filters.ts`, `src/keys.ts` — поиск, фильтры, привязки
  клавиш и чтение настроек; `src/model.ts` — общие типы и сообщения.
- `src/action-hints.ts` — контекстные подсказки по текущему режиму и раскладке.
- `src/query-action.ts` — распознавание адреса/поиска; `src/query-launcher.ts` —
  открытие адреса и нативный поиск через search API в новом tab текущего окна.
- `src/history-suggestions.ts` — поиск по индексу истории, ранжирование, разрешение
  и проверка предложенных адресов; `src/suggestion-search.ts` — задержка ввода
  и защита от устаревших ответов в picker.
- `src/previews.ts` — очередь и ограниченный кэш снимков;
  `src/preview-view.ts` — отложенный запрос и отображение preview.
- `src/browser.d.ts` — используемая поверхность WebExtensions API;
  `src/demo.ts` — демонстрационные данные без браузерного API.
- `public/` — manifest и иконка. `tests/` — модульные тесты;
  `scripts/` — изолированные проверки Zen и диагностика.
- `dist/` — результат Vite; меняй исходники, а не сгенерированные файлы.
- `README.md`, `PRIVACY.md`, `BUILDING.md`, `CONTRIBUTING.md` и `CHANGELOG.md` —
  публичная документация. `docs/` содержит тексты GitHub/AMO, заметки для ревью
  и чеклист публикации. Черновики не означают выполненную публикацию.

## Инварианты фоновой части

- Сохраняй сериализацию жизненного цикла вкладок. Захват preview выполняется
  отдельно и не должен блокировать очередь действий или хоткеи.
- Сигнал завершения `onRemoved` передавай вне очереди: операция закрытия может
  ждать его, уже удерживая очередь.
- Не активируй закрытые ID и не создавай обычную вкладку заново по сохранённому URL.
- Сохраняй существующий add-on ID и legacy-ключи предпочтений при косметическом
  переименовании: смена идентичности расширения может потерять текущие настройки.
- Не смешивай приватные и обычные окна ни в результатах, ни в кэше preview.
- История сайтов доступна только при historySuggestions и optional-разрешении
  history, исключительно в обычных окнах. Чтение индекса идёт вне очереди действий,
  открытие явно выбранной подсказки — внутри. Предложенные адреса хранятся только
  в памяти; отзыв разрешения, отключение и удаление истории инвалидируют ответы.
  Открывать можно только предложенные этому picker HTTP(S)-адреса; вкладка,
  открывшаяся за время выбора, используется повторно.
- Preview не должен активировать вкладку или будить выгруженную страницу.
  Учитывай отзыв разрешений, навигацию и поздние ответы захвата.
- launch-query — явное действие пользователя в той же очереди операций.
  Провайдер нативного поиска не задаётся расширением, tabId задаётся явно;
  новый tab принадлежит окну и приватному контексту вызывающего picker.
  При ошибке удаляется только созданный этой операцией неактивный about:blank,
  если пользователь ещё не изменил его.

## Стиль и сборка

Рабочие сессии не меняют видимость, порядок, закрепление и нативные группы вкладок.
Обычный каталог хранится в storage.local.workSessions, membership — в
sessions.setTabValue, текущая сессия окна — в sessions.setWindowValue. Приватные
каталог, принадлежность и назначения используют только storage.session и очищаются
после закрытия последнего приватного окна. Каталоги разделены по приватности;
сессия может содержать вкладки нескольких окон. Удалённые session ID разрешаются
в отсутствие назначения, включая восстановленные вкладки. Встроенной Unsorted нет;
старые значения unsorted читаются как отсутствие назначения. Начальный выбор окна
— All sessions (ID all); этот выбор также сохраняется через setWindowValue и
в приватном storage.session. ID all обозначает общий просмотр, а не принадлежность
вкладки. Нет отдельного локального фильтра, который может расходиться с сохранённым
выбором окна. TabItem.sessionIds — список сессий; metadata использует массив ID,
чтение старых одиночных строк поддерживается. После успешного focus выбор вкладки
через picker добавляет сессию вызывающего окна, сохраняя прежние назначения;
All sessions ничего не добавляет. Нативная активация и preview не меняют назначения.
Callback контроллера также охватывает повторное использование вкладки из истории.
При удалении сессии исключается только её ID; явный Move заменяет весь список,
а Move в All sessions очищает его. Закрытие browser tab закрывает общую вкладку.
Новые вкладки используют текущее назначение, дети ссылок наследуют все сессии
источника; auto-add можно отключить.
Явные открытия через picker назначаются текущей сессии до запуска поиска, даже
при отключённом auto-add. Все операции и события onCreated идут в общей очереди.

Используй строгий TypeScript, ES-модули, отступы в два пробела, одинарные кавычки
и точки с запятой. Функции и переменные — `camelCase`, типы и классы — `PascalCase`.
Следуй именованию соседних файлов, например `preview-view.ts`.
Локальные TS-импорты содержат `.ts`; импорты типов оформляй через `import type`.

Форматтер и отдельный линтер TypeScript не настроены. `npm run build` сначала
запускает `tsc --noEmit`, затем Vite с целью Firefox 140. Не добавляй новый
инструментарий форматирования ради несвязанной правки.
При выпуске согласуй версии в `package.json`, `package-lock.json` и
`public/manifest.json`; правки только документации не требуют новой версии.
